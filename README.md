# OmniDesk

常驻 macOS 菜单栏的轻量工具箱：截图与 OCR、滚动长截图、框选翻译、录屏、实时网速和 Finder 文件工具。

**版本 1.1.31 · Apple Silicon · macOS 15+**

## 主要功能

| 功能 | 支持内容 |
| --- | --- |
| 截图与 OCR | 区域、窗口、全屏截图；本机中英文识别、文字复制 |
| 长截图与图片编辑 | 滚动拼接、矩形、箭头、画笔、文字、遮挡、贴图及多图拼接 |
| 框选翻译 | 菜单栏点击翻译图标，拖框选字后自动识别并调用 macOS 系统翻译；支持语言切换、朗读、复制、置顶 |
| 录屏 | 区域或全屏、系统声音、麦克风、摄像头小窗、30 / 60 fps、MP4 |
| 网络监控 | 实时上传下载网速、流量图表、接口与 IP、延迟与抖动、进程流量排行及 Kill |
| Finder 文件工具 | 新建模板、剪切与移动、批量重命名、路径复制、哈希、图片转换；菜单显隐与排序 |
| 个性设置 | 各工具的全局快捷键、菜单栏图标间距及网速右侧留白 |

## 安装与使用

1. 打开 Apple Silicon 版 DMG，将「OmniDesk.app」拖入「应用程序」；升级前先退出旧版。
2. 启动后点击菜单栏**工具箱图标**打开菜单，点击**网速**查看网络详情，点击独立的**翻译图标**开始框选翻译。
3. 在「通用设置」中配置快捷键、菜单栏间距和权限。

**框选翻译：**拖框选择屏幕文字，松开鼠标自动识别并翻译，Esc 取消。等待时可取消或重新框选；重复内容使用进程内缓存，macOS 26.4+ 优先使用系统低延迟模型。首次使用可能需要下载语言包。

**滚动长截图：**仅框选滚动正文，缓慢向下滚动，完成后点击「结束截图」；动画、固定遮挡或滚动过快可能影响拼接。

截图、翻译框选和录屏需要屏幕录制权限；麦克风、摄像头、独立鼠标菜单及 Wi-Fi 详情按需申请权限。Finder 扩展可在系统扩展设置中启用。

安装包使用本地 ad-hoc 签名，未经 Apple 公证。若系统阻止打开，可先尝试启动一次，再到「系统设置 → 隐私与安全性」选择「仍要打开」。

**Kill 会强制结束进程，可能丢失未保存内容；权限不足时不会自动提权。**

## 快捷键

| 功能 | 默认快捷键 |
| --- | --- |
| 区域截图 | ⌃⌥⌘A |
| 滚动长截图 | ⌃⌥⌘S |
| 开始 / 停止区域录屏 | ⌃⌥⌘R |

其余工具默认未绑定。在「通用设置 → 快捷键」中点击录入、清除或恢复默认，更改立即生效，并检查组合冲突。

## 数据与隐私

截图、OCR、图片处理、录屏和菜单栏网速采样在本机完成。系统翻译使用 Apple Translation 框架，译文缓存仅保留在当前进程内。

网络详情面板展开时查询公网 IP、检测 HTTPS 连通性并读取进程流量，关闭后停止这些操作。Google / 百度网页翻译会将主动提交的文字发送到对应网站。

## 从源码构建

安装 macOS Command Line Tools 后，在项目目录运行：

```bash
python3 scripts/build.py
```

生成路径：`.build/release-1.1.31/OmniDesk.app`。构建目录已存在时，使用 `python3 scripts/build.py --refresh-binary` 更新可执行文件。
