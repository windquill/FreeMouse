# 原生窗口长截图验收

在项目根目录使用本机原生 Python 运行：

```sh
/usr/bin/python3 scripts/scroll-validation/run.py
```

脚本编译正式采集源码和独立的 AppKit 测试窗口。测试窗口只显示固定种子的生成内容，置于选区上方；采集范围缩进窗口边界，避免包含其他窗口内容。使用已有屏幕录制权限，预检不通过就停止，不主动申请权限。自动滚动验收只在已有辅助功能权限时运行。

所有测试源码、日志、缓存和生成图片位于本项目；产物保存在 `.build/scroll-validation`。测试结束通过控制文件关闭自己创建的窗口；超时只终止自己启动的子进程。

验收内容：

- 16 个已知滚动位置与长图高度逐步核对，最终原生截图末尾 64 行像素一致。
- 点击完成后 220ms 才出现的尾帧仍进入输出。调度使用绝对点击时间，避免 `NSButton.performClick` 的同步动画延迟改变场景。
- 完成中取消不会输出图片。
- 暂停期间由测试页面自行移动，完成时给出未确认警告。
- 已有辅助功能权限时，自动滚动须实际驱动原生 `NSScrollView`，最终高度与页面位移一致。

每轮都会建立独立结果目录，使用 `RESULT_PASS` / `RESULT_FAIL` 表明结果。控制器验收只检索当前可见且就绪的控件，避免读取 AppKit 保留的已关闭窗口。
