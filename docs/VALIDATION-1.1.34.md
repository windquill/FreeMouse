# OmniDesk 1.1.34 验证记录

本版新增菜单栏启动项管理、风扇控制和应用输入法，沿用 Apple Silicon/macOS 15+、现有 bundle ID 和快捷键编号；三项可在设置中绑定快捷键。

2026-10-21：相关 15 个套件共 96 项测试通过。应用、Finder 扩展与独立风扇助手构建成功，应用深度严格签名校验通过。随包风扇助手的无硬件 `--self-test` 返回预期 fixture JSON。

## 验证范围

- 启动项：项目内夹具应用添加默认停用，登录启动 plist 参数为字面值，启用/停用/移除仅修改匹配归属的文件，外来文件和符号链接保护，伪造标识拒绝。
- 输入法：启用、应用匹配、当前输入源、可用输入源和自身应用的决策组合；编码往返、无效记录和重复规则处理。快速切换应用时校验真实前台应用，避免过期事件误切。
- 风扇：合法硬件上限、无效与缺失数据拒绝、目标值/模式校验、参数引用。助手 `--self-test` 只验证固定 JSON 和零值/浮点/fpe2 纯解码，在实例化 SMC 前退出。
- 独立审查：修复等待管理员授权期间关闭面板仍可能启动最大转速的问题；以控制意图和会话代号隔离迟到回调。修复合法 0 RPM 与无风扇数据被误判的问题。
- 保留归档、菜单、快捷键、翻译及网络相关回归。

## 行为边界

启动项仅管理 OmniDesk 添加的应用；其他启动配置只读展示并提供系统设置入口。启停影响下次登录，不调用 launchctl，不自动运行或退出所选应用。

风扇助手仅由用户点击后按需管理员授权，校验连接 UID 与 PID，只接受固定的最大转速/自动/心跳协议。无常驻服务安装。退出、关闭面板、睡眠、连接断开、15 秒心跳丢失或 10 分钟超时后恢复自动，真实模式恢复失败时保持重试。当前只恢复本应用控制的会话，不接管其他软件的手动模式。

最大转速按硬件上限写入并校验目标值，实际转速需要逐渐上升；固件可能拒绝。开发验证没有调用真实 SMC 读取或控制，也没有修改真实启动项和输入法。真实硬件、管理员授权交互、下次登录启动及用户应用中的自动切换仍需安装后验收。

本轮不宣称全项目测试全部通过；打包使用本地临时签名，没有 Apple 开发者公证。日志位于 `.build/system-utilities-tests.log` 与 `.build/system-utilities-build.log`。
