# OmniDesk 系统工具设计

用户要求菜单栏提供开机启动项管理、风扇最大转速控制，以及按应用自动切换输入法。继续沿用本次会话全部批准的执行方式，不在开发测试中更改本机启动项、输入法或风扇。

## 启动项

独立窗口显示 OmniDesk 管理的应用和系统启动项。添加应用后创建带独立命名空间的用户 LaunchAgent；启用在下次登录生效，禁用只移除经过归属校验的自有文件。系统项目仅展示必要标识，提供系统登录项设置入口，不改动第三方服务。不得读取或展示服务参数中的凭据。

## 风扇

独立窗口读取 SMC 实际风扇及当前/最大转速，提供系统自动与最大转速。仅使用硬件报告的有效上限，不提供关闭风扇或低于系统下限的控制。写入需管理员授权时交给系统提示。控制失败不展示虚假成功，部分写入失败恢复自动；最大转速应有超时和退出恢复策略。无风扇设备明确提示不支持。开发验证不实际写入硬件。

## 输入法

窗口以应用图标、名称、输入法下拉列表呈现规则，支持添加、删除、暂停以及实际成功切换次数。通过 TIS 枚举已启用可选输入源，以 bundle ID 和输入源 ID 保存；仅在前台应用匹配规则时切换。无规则、输入源不可用或已是目标时保持当前输入法。

## 集成与验收

三个入口放入现有工具箱菜单栏菜单，并加入可配置快捷键列表；不新增三个常驻图标。应用启动监听输入法切换事件，退出时停止监听和恢复风扇。保持现有 OCR、翻译、网络和右键功能。

使用注入依赖和项目内测试样本验证持久化、规则决策、启动项归属、风扇范围和恢复策略；构建 Apple Silicon/macOS 15+ 的 1.1.34 DMG。真实硬件最大转速和登录后启动需要用户安装后验收，不能以模拟测试代替。
