# 启动项与风扇修订设计

用户反馈最大转速报 SMC 写入或校验失败，要求修复；启动项必须看到其他软件是否开机启动并可直接设置，不能局限于 OmniDesk 新增项目。

## 风扇

先读取本机型号、转速和模式，不自动修改真实硬件。将固件拒绝、瞬时读回与模式切换未完成分开处理，保留逐阶段错误。Apple Silicon 控制解锁和模式等待应按实际协议有界重试，写入成功不能仅凭立即读回判断失败；最终仍需确认模式与目标值。控制耗时不得误触心跳断开恢复。硬件最大值、部分失败恢复自动和独立 watchdog 不变。

## 启动项

展示已安装应用与实际系统登录项状态，并支持通过 System Events 直接新增/删除登录项。通过 launchctl 的 disabled override 查询与切换用户 LaunchAgent 和允许管理的系统后台项；系统域操作由用户点击后按需请求管理员授权。不通过重启/bootout 立即停止正在运行的软件。未知或不可管理的项目明确显示原因，不能把未知显示为关闭。

保留旧自有启动项记录兼容与归属保护，避免已有记录重复。后台项目和登录应用是不同机制，界面标明来源、启用含义和权限。自动化读取需系统 Automation 授权，不读取或输出敏感参数和环境变量。

## 验证

使用模拟 SMC 时序验证接受写入后延迟生效、解锁等待、最终拒绝、超时与恢复。使用项目内夹具验证脚本引用、登录项解析、禁用状态解析及标识校验。开发测试不实际增删登录项或启停系统服务。构建 1.1.35 build 37 并验证 DMG；真实 SMC 最大转速仍须用户主动验收。
