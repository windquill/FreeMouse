# OmniDesk 右键压缩与解压

用户目标：在 Finder 右键一级菜单直接解压，在一级「压缩」的二级菜单选择格式；支持 tar.gz/tar.bz2 等尽可能多的格式，压缩排除 macOS 附带元数据。

方案：系统 libarchive 引擎，经小型 C 桥接调用，不安装 Homebrew 工具。菜单配置沿用排序/隐藏系统和稳定 action tag。Finder 扩展与主程序共享格式目录和本机能力探测，只有可创建的格式出现在菜单。

创建候选：zip、7z、tar、tar.gz、tar.bz2、tar.xz、tar.lzma、tar.zst、tar.lz4、tar.Z、cpio、cpio.gz、xar；以本机真实能力为准。读取使用 libarchive 自动检测，支持的常见格式包括 ZIP/7z/TAR 系列及可读取的 RAR/CPIO/XAR/ISO 等；不提供 RAR 创建，不宣称加密/分卷支持。

压缩输出与源文件同级；单选以源名命名，多选使用 Archive。解压每个归档到同级同名目录。冲突自动编号，最终发布必须拒绝覆盖。操作在后台执行，应用显示处理状态，操作期间保持忙碌防止重入和退出。

排除：__MACOSX、.DS_Store、._*、.Spotlight-V100、.Trashes、.fseventsd、.TemporaryItems、.VolumeIcon.icns 等系统元数据；保留 .git/.env 等普通隐藏文件；不读取或上传凭据内容，仅按用户选区进行归档。

安全与事务：写入随机私有暂存目录/文件，成功后原子发布，失败清理自身暂存。读取拒绝绝对路径、..越界、危险软/硬链接、设备节点及路径冲突；防止解压写出目标目录。输出不恢复所有者/特权权限/扩展属性/ACL。资源使用有上限，拒绝损坏或不支持的归档并给出错误。

验证：格式能力探测与实际创建/解压往返；多选/Unicode/空格；元数据过滤且普通隐藏文件保留；越界/链接/损坏/重名；一级解压和二级压缩的菜单结构、稳定 action 路由；现有菜单、快捷键及网络回归。构建新的 OmniDesk DMG 并验证签名和校验和。

## 后续用户修订：三平台常用格式

不能仅依赖系统 libarchive。打包官方独立7-Zip26.04用于RAR/RAR5、ZIPX、安装包/镜像/分卷/加密读取补充；引擎限制在私有暂存目录写入，解压后再次校验，再排他发布。密码通过stdin传给辅助进程，不出现在参数、环境或日志。

增加自带Zstandard1.5.7和LZ4 1.10.0库，不依赖本机Homebrew。创建增加独立gz/bz2/xz/lzma/zst/lz4（单文件），激活tar.zst/tar.lz4；文件夹和多选继续使用归档容器格式。加密归档由用户按需提供密码；不支持RAR创建。UI清楚区别创建与仅读取能力，不能仅凭扩展名宣称所有变种可用。
