# Continuous scrolling capture Implementation Plan

**Goal:** Rebuild long capture interaction around the documented iShot flow and persistent streaming.
**Spec:** ../specs/2026-10-14-scroll-v1.1.md
**Architecture:** Stream source latest-only buffer → serial actor stitching engine → bounded preview and main-actor flow controller. Separate selection controls and output actions.
**Tech Stack:** Swift5/macOS15, AppKit, ScreenCaptureKit, CoreImage, Carbon; no external dependencies.

## Global Constraints
- Preserve original files and 1.0 outputs. Publish local 1.1 DMG/source only.
- Never copy vendor code/resources or bypass permission prompts.
- Exact display-relative top-left crop, Retina output; exclude app UI.
- Every stream/capture/shortcut/task removed at cancellation, no stale callback.
- Report live testing gaps truthfully.

## Review Focus
- Finish while frame processing and stale cancellation.
- Stationary manual frames vs actual auto lack-of-progress.
- Toolbar covering target, negative display origins.
- Small text movement, reverse scroll and bounded memory.
- Versioned package contents match signed release.

## Tasks
1. Agent: benchmark ScrollStitcher, add bounded preview/metrics, meaningful regressions. Keep existing API.
2. Agent: ScrollFrameSource.swift, one SCStream 15fps newest-only sink, generation-safe start/stop, buffer tests.
3. Root: test ScrollCaptureFlow and overlay layout first; replace controller with persistent manual follow, automatic scrolling/backpressure, preview, local/transient shortcuts and queued output.
4. Root: selection S entry + action bar, AppModel activity guard/output dispatch, editor save/OCR bridge; update Chinese instructions.
5. Independent scoped review, integrated tests and release benchmarks, signed v1.1 DMG/source, verify CRC and packaged binary identity.
