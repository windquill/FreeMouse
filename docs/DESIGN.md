# 自在工具箱设计

用户目标：获得可本机安装的免费原生 macOS 工具，重点是截图、长截图、录屏。参考 iRightMouse Pro 2.4.7 的公开功能；官网说明截图联动 iShot，因此采用独立实现将这几类功能合并。用户明确授予本会话开发、构建、验证授权，按该授权直接完成设计和执行。

备选：基于网页封装难以完成全局选择与系统采集；复用原版二进制无法提供独立可维护软件；选择 Swift + AppKit/SwiftUI + ScreenCaptureKit + Vision，不含任何原版代码、图标、文案或授权逻辑。

交付：自在工具箱 FreeMouse.app、DMG、源代码、中文安装使用说明与真实验证记录。目标为当前 Apple Silicon Mac，最低 macOS 15。中文界面，离线，不需要账号、订阅、上传或第三方依赖。可尝试同时构建 Intel 版本，但不作为本机安装阻碍。

组件：
1. 截图：菜单栏和全局快捷键，当前屏幕、区域、窗口；选择覆盖层支持多显示器、Esc取消；使用 ScreenCaptureKit 排除本应用窗口。
2. 长截图：用户选定区域，手动滚动或自动滚动，周期采集，检测上下重叠并拼接；重复帧不增加高度，无法可靠匹配时提示；限制总像素与帧数避免内存无限增长；停止后进入编辑器。
3. 编辑器：缩放预览、画笔、矩形、箭头、文字、遮挡、撤销、复制、另存PNG/JPEG、贴图、Vision OCR中英文识字、导入图片和多图拼接。
4. 录屏：全屏/区域、30或60fps、可选系统声音与麦克风、倒计时、停止并完成MP4；开始/停止/失败清晰区分，拒绝权限不创建假成功文件。
5. 文件：选择文件后复制路径、SHA256、图片转格式、创建文本文件和文件夹、批量重命名（先预览、拒绝覆盖）、在终端打开目录；提供系统服务入口，若可行提供Finder扩展。
6. 设置：权限状态与系统设置跳转、保存位置、启动时显示窗口、全局快捷键、最近文件。

所有媒体仅在明确用户操作后采集，首次系统屏幕录制/麦克风/辅助功能授权由用户在系统界面授予，软件不得绕过。自动滚动需要辅助功能；手动滚动无需该权限。

真实性：不宣称与两款成熟商业软件完整1:1，也不宣称Apple公证。没有开发者证书时采用本地ad-hoc签名，附正确的首次打开说明。系统权限或执行环境阻止端到端采集时如实记录，仍做构建、算法、文件输出、签名和归档验证。

验证重点：Retina与多屏坐标、取消、重复/低纹理/固定栏拼接、权限拒绝、录制异步完成、文件覆盖保护、DMG内容完整性。核心算法用独立合成输入单元测试，UI用实际启动检查。
