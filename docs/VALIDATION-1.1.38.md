# OmniDesk 1.1.38 验证记录

2026-10-21：17 个相关套件共 108 项测试通过。应用、Finder 扩展和辅助程序构建及深度严格签名校验通过。

## 应用运行控制

新增 ApplicationRuntime，通过 NSWorkspace 与 NSRunningApplication 实现启动、激活、隐藏/取消隐藏、正常退出、强制退出和重启。窗口打开时订阅启动、结束与隐藏通知，关闭时停止监听。

启动前验证本地 APPL 应用包及有效可执行文件，避免重复创建新实例。正常退出后最多等待 6 秒确认实际结束；未退出时显示等待保存或确认，不自动强退。重启只有在原实例都已结束且没有替代实例时才继续启动。

结束进程前核对 PID、应用路径、bundle ID、启动日期、内核启动时间与所属账号。强退确认前捕获不可变快照，确认后若进程重启、PID复用或实例集合变化则拒绝。OmniDesk 自身和 Finder、Dock、loginwindow、SystemUIServer、WindowServer 等受保护应用不通过此入口结束，不自动提权结束其他账号进程。

## 实际 API 验证

在项目 `.build/app-runtime-fixture` 创建唯一 bundle ID 的专用测试应用，使用生产 ApplicationRuntime API 完成：

- 启动后检测到实际运行 PID。
- 测试应用拒绝退出时，重启操作失败，原 PID 保持不变。
- 允许退出后重启成功，观测到新 PID。
- 以明确快照执行强制退出，观测到实例结束。
- 再次启动并正常退出，确认列表为空。

日志在 `.build/application-runtime-fixture.log`。仅操作专用测试应用，没有为测试关闭或重启现有用户软件。隐藏/前台显示等接口已编译检查，本轮专用应用实测聚焦上述生命周期。
