# 1.1.30 验证记录

- macOS 15+ / Apple Silicon；版本 1.1.30，构建 32。
- 定位：先前代码在本地已经识别语言后仍向 TranslationSession 传入 source=nil；当前 SDK/本机默认采用 highFidelity。改为传入已识别语言，macOS 26.4+ 显式使用 lowLatency。
- 本机直接会话预热基准，固定文本 Tests/FreeMouseTests：默认模型 0.080 秒，lowLatency 0.017 秒；只代表本机已安装模型的单次预热样本，不代表冷启动或所有环境。
- 使用生产 SystemTranslationView/State 的独立原生应用验证：Tests/FreeMouseTests 从开始请求到译文显示约 0.479 秒，译文「测试/FreeMouse测试」。此值包括视图调度与语言准备，模型已安装。
- 真实窗口点击「重新翻译」验证「翻译完成（缓存）」；缓存仅在进程内保存，16 条上限，每条原文+译文最多 64 KB。
- 46 项测试（5 组）通过；新增明确原文语言/低延迟策略、取消与过期结果、超时解锁、缓存和更换目标语言测试。新测试在实现前失败。
- 连续请求回归实测发现 SwiftUI 在 Configuration.invalidate 后可能保留旧 action 闭包；为每个请求设置独立 view identity 后解决。原生自动序列验证：第一段 0.132 秒，第二段 0.070 秒，第三次重复请求命中缓存，记录 SEQUENCE_PASS。不同测试采样不可直接等同于所有环境速度。
