# 1.1.23 build25 自定义快捷键

在通用设置新增快捷键区域，覆盖区域截图、长截图、全屏截图、窗口截图、开始/停止区域录屏。支持按组合键录入、Esc取消、清除单项及恢复默认，配置存入应用偏好，修改即时生效。

默认区域⌃⌥⌘A、长图⌃⌥⌘S、区域录屏启停⌃⌥⌘R；其余默认未设置。保留实际Carbon虚拟键码，必须包含Command、Control或Option；显示使用常见按键标签。重复组合和注册失败不保存，失败恢复旧注册并提示。启动逐项注册，被占用项不影响其他功能。

录入期间注销本应用全局热键，本地keyDown监视避免菜单命令抢先触发；Esc、离开设置、主窗失焦/关闭/最小化或应用失去活动状态均结束录入并恢复注册。菜单栏及截图页组合键显示同步更新。

验证：271项/40组完整回归通过，其中7项新增测试覆盖持久化/清除、重复及无修饰键拒绝、注册失败回滚、录入暂停及取消恢复、默认恢复、修饰键转换、冷启动部分冲突保留。设置测试使用内存存储，未改动用户快捷键偏好。

原生验证通过：NSHostingView设置面板实际录入组合键、Esc取消、注册恢复；Carbon使用少见测试键注册后立即释放。仅截图验证程序自身窗口检查布局。日志`.build/capso-import/shortcuts-native-final.log`，预览`.build/shortcut-validation/settings.png`。未做跨进程物理按键注入或重启已安装应用验收。

保留原有采集、拼接和文件工具实现。未替换已安装应用，未推送远程。
