# OmniDesk 1.1.33 验证记录

## 功能范围

Finder 与独立右键菜单中，解压位于一级菜单，压缩格式位于二级菜单。Apple Silicon / macOS 15+。

提供 18 种创建格式：ZIP、7z、TAR、tar.gz、tar.bz2、tar.xz、tar.lzma、tar.zst、tar.lz4、tar.Z、CPIO、cpio.gz、gz、bz2、xz、lzma、zst、lz4。最后六种仅支持单个普通文件；目录和多文件应选择归档组合格式。

读取由系统 libarchive 与内置官方 7-Zip 26.04 补充，覆盖 Windows、macOS、Linux 常用归档，包括 RAR/RAR5、ZIPX、CAB、ARJ、MSI、WIM、DMG、XAR、DEB、RPM、ISO 等。具体编码、镜像文件系统及变种取决于引擎；并非所有 EXE、DMG、MSI 都是可展开的归档。RAR 不提供创建。

加密 ZIP、7z 和 `.7z.001` 分卷有实际生成样本测试。经典 RAR/ZIP 分卷文件的发现范围有单元测试，但本轮未用实际经典 RAR/ZIP 分卷做完整解压验收。选择首卷，所有分卷应放在同一目录。

## 检查项目

2026-10-21：相关 12 个测试套件共 85 项通过。发布构建成功，应用、Finder 扩展及内置辅助程序的深度严格签名验证通过。构建与测试日志保存在本机 `.build/archive-build-1.1.33.log`、`.build/archive-cross-platform-tests.log`。

- 所有可创建归档格式的中文路径、空目录、普通隐藏文件往返与 macOS 元数据过滤。
- 六种单文件流：空文件、300KB 数据、2MB 高压缩比数据往返、截断失败、不覆盖既有输出。
- 官方 LZ4F 生成的 4MiB 块与内容校验帧读取。
- 加密 ZIP/7z：无密码、错误密码、正确密码；密码由标准输入传入，不进入参数或偏好设置。
- `.7z.001` 分卷解压、拒绝非首卷、经典分卷发现不读取无关同名后缀文件。
- 辅助引擎无法向暂存目录外写入，无法读取无关的相邻文件内容；恶意 TAR 路径、越界及循环链接检查。
- Finder 菜单、格式标签与设置兼容，以及翻译、快捷键、网络功能相关回归。

## 安全边界与限制

使用私有暂存目录与排他重命名发布结果；失败清理暂存内容，不覆盖源文件或已有输出。7-Zip 辅助进程强制使用 macOS 文件系统沙箱并禁止网络访问；未提供无沙箱回退。

单次输出限制 20GiB、100000 项、256 层。辅助进程运行期间每 500ms 检查，可能短暂超过数量或大小限制；完成后仍进行最终校验。辅助进程超时为 300 秒。拒绝特殊文件、硬链接、越界或循环符号链接。

本轮验证不代表对所有归档变种的兼容承诺。未重新进行真实 Finder 中鼠标操作的人工验收；本机仅进行了相关测试与打包验证。安装包为本地临时签名，没有开发者公证。
